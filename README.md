# ☀️ [인천 부광고등학교] 태양광 패널 & 이중 편광판 광학 실험 시뮬레이터

선생님께서 학생들과 함께 과학 수업 및 탐구 활동에서 시연하고, 가상 시뮬레이션 데이터와 실제 실험실 측정 데이터를 엑셀로 비교 분석할 수 있는 통합 웹 시뮬레이터입니다.

---

## 🚀 빠른 시작 방법

### 웹 브라우저에서 바로 열기 (로컬)
1. **`시뮬레이터_실행.bat`** 또는 **`index.html`** 파일을 더블 클릭하면 기본 웹 브라우저(크롬, 엣지 등)에서 즉시 실행됩니다. (별도 프로그램 설치 불필요)
2. 인터넷이 연결되어 있으면 **인천 부광고등학교(위도 37.498°N, 경도 126.738°E)** 좌표의 실시간 일사량 및 기상 데이터(Open-Meteo API)를 자동으로 동기화합니다.

### GitHub + Vercel 무료 온라인 배포 방법
1. GitHub에서 새 저장소(Repository)를 생성한 뒤 현재 폴더를 푸시합니다:
   ```bash
   git remote add origin <GitHub_저장소_URL>
   git push -u origin main
   ```
2. [Vercel](https://vercel.com)에 GitHub 계정으로 로그인 후 **`Add New... -> Project`** 에서 해당 저장소를 Import 합니다.
3. 별도의 Build Command 설정 없이(정적 HTML 사이트, `vercel.json` 포함됨) **`Deploy`** 버튼을 누르면 즉시 온라인 URL이 생성되어 학생들과 링크로 공유할 수 있습니다.

## 🌟 주요 기능 안내

### 1. 🎛️ 자유로운 각도 및 광학 파라미터 제어
- **편광 모드 3단 전환**:
  - **편광판 없음**: 자연광 그대로 패널에 입사 (기준 대조군).
  - **단일 편광판**: 무편광 자연광이 편광판 1장을 통과하여 단일 선형 편광으로 걸러짐 (약 50% 투과).
  - **이중 편광판**: 제1 편광판($\theta_1$)과 제2 편광판($\theta_2$)의 각도를 각각 조절하여 **말뤼스의 법칙($I = I_0 \cos^2\Delta\theta$)**을 정밀하게 구현.
  - **실제 광학 손실 보정**: 편광필름 자체 흡수율(86% 등) 및 90° 직교 시 미세하게 새어 나오는 **소광비(Extinction ratio, 0.05%)** 조절 가능.
- **태양광 패널 설치 각도**:
  - **경사각 (Tilt, 0° ~ 90°)**: 인천 지역 연간 최적 경사각인 **37° 원클릭 버튼** 제공.
  - **방위각 (Azimuth, 90° ~ 270°)**: 정동(90°), 정남(180°), 정서(270°) 원클릭 프리셋.
- **환경 및 모듈 스펙 세부 설정**:
  - 기준 일사량($\text{W/m}^2$), 외기 온도(°C), 시간대 슬라이더(06:00 ~ 18:30).
  - 패널 면적($\text{m}^2$), 광전 효율(%), 온도 계수(%/°C) 등 학교 실험 장비 스펙에 맞춤 설정 가능.

### 2. 🌐 인천 부광고등학교 실시간 날씨 API 연동
- Open-Meteo Solar Forecast API를 통해 부광고등학교 위치의 현재 기온, 운량(구름 양), 직달일사량 및 산란일사량을 실시간으로 불러와 시뮬레이션에 반영합니다.
- 날씨 소스를 '가상 조건 직접 설정'으로 변경하면 흐린 날이나 야간에도 자유롭게 원하는 일사량을 시뮬레이션할 수 있습니다.

### 3. 🎨 실시간 3D/2D 광학 캔버스 뷰
- 태양의 고도와 방위각에 따른 하늘 위치 변화.
- 태양광 패널의 실제 3D 경사각 렌더링.
- 회전하는 이중 편광판의 슬릿(격자축)과 빛이 편광판을 통과하면서 진폭이 줄어드는 광파동 애니메이션 구현.

### 4. 📊 엑셀 데이터 연동 & 실제 실험 데이터 비교 분석 (핵심!)
- **시뮬레이션 데이터 엑셀 내보내기**:
  - 현재 설정된 조건 및 0°~90° 각도별 이론 발전량 표가 담긴 `.xlsx` 파일을 원클릭으로 다운로드합니다.
- **학생 실험 기록용 엑셀 양식 배부**:
  - 학생들에게 나누어줄 수 있는 깔끔한 서식의 `학생_실험_기록용_양식.xlsx` 제공 (전압/전류 입력 시 전력 자동 계산 수식 포함).
- **실제 실험 엑셀 파일 업로드 & 대조**:
  - 학생들이 실험 후 기록한 엑셀 파일(`.xlsx`, `.csv`)을 드래그앤드롭하여 업로드하면, **[이론 곡선 vs 실제 학생 측정값]** 중첩 그래프와 함께 **MAPE(평균 절대 오차율)** 및 **$R^2$(결정계수)**가 자동 계산됩니다.
  - 수업 시연을 위한 `실제_실험_데이터_샘플(인천부광고).xlsx` 및 '가상 샘플 데이터 불러오기' 버튼이 내장되어 있습니다.

## 👩‍🏫 추천 수업 진행 흐름 (차시 지도안 예시)

1. **[도입] 편광의 개념과 말뤼스의 법칙 학습**
   - 시뮬레이터 상단의 '실험 원리/이론' 버튼을 눌러 $I = I_0 \cos^2(\Delta\theta)$ 수식을 확인합니다.
   - 편광판을 '없음' $\rightarrow$ '단일' $\rightarrow$ '이중(0°)' $\rightarrow$ '이중(90°)'으로 바꾸며 발전량이 어떻게 변하는지 관찰합니다.
2. **[탐구 1] 패널 경사각과 태양 고도**
   - 인천 부광고의 위도(37.5°N)에서 왜 경사각을 37도 전후로 두었을 때 정오 발전량이 최대가 되는지 확인합니다.
3. **[탐구 2] 가상 시뮬레이션 데이터 엑셀 다운로드**
   - '시뮬레이션 데이터 엑셀 받기'를 클릭하여 이론값 테이블을 저장합니다.
4. **[탐구 3] 실제 실험 및 엑셀 기록**
   - 실험실에서 태양광 패널, 할로겐 램프, 편광필름 2장, 멀티미터를 준비합니다.
   - 각도차(0°, 15°, 30°, 45°, 60°, 75°, 90°)에 따른 전압(V)과 전류(mA)를 측정하여 `학생_실험_기록용_양식.xlsx`에 기록합니다.
5. **[정리 및 오차 분석 토론]**
   - 작성한 엑셀을 시뮬레이터의 '실제 실험 엑셀 비교 분석' 모달에 업로드합니다.
   - **토론 주제**:
     - *왜 90° 직교 상태에서도 전력이 완전히 0W가 되지 않고 미량이 측정될까?* (소광비, 실내 천장등의 산란광 유입)
     - *왜 편광판 1장만 넣어도 전력이 절반보다 더 떨어질까?* (필름 표면 반사 및 흡수 손실)
